# Security Policy

## Supported Versions

The following versions of Multi-LLM Debate Arena are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you find a security vulnerability, please do NOT open a public issue. Instead, report it privately to the maintainers.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Responsible Disclosure

We ask that you follow responsible disclosure practices and give us reasonable time to fix the vulnerability before making it public.
