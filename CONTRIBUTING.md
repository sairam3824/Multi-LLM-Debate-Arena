# Contributing to Multi-LLM Debate Arena

Thank you for your interest in contributing to the Multi-LLM Debate Arena!

## How to Contribute

1.  **Report Bugs**: If you find a bug, please open an issue.
2.  **Suggest Features**: If you have an idea for a new feature, please open an issue to discuss it.
3.  **Submit Pull Requests**:
    *   Fork the repository.
    *   Create a new branch for your feature or bug fix.
    *   Write your code and add tests if applicable.
    *   Ensure all tests pass and the project builds successfully.
    *   Submit a pull request.

## Development Setup

1.  Clone the repository.
2.  Install dependencies: `npm install`.
3.  Set up the database: `npm run db:push`.
4.  Start the development server: `npm run dev`.

## Code Style

*   Use TypeScript for all new code.
*   Follow the project's existing coding patterns.
*   Ensure your code is well-documented.
